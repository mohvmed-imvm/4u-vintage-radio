4U Vintage Radio — prototype
1) Open index.html in Chrome to preview.
2) For each order, edit the STATIONS array near the bottom of index.html.
3) Put audio files in an `assets` folder beside index.html, e.g. assets/station-1.mp3.
4) Replace each station's image URL and edit the final notebook message/photos.
5) You can add or remove station objects; the station buttons and "heard all" check update automatically.

Audio tip: use direct .mp3 or .wav files. External fonts and demo photos need an internet connection.
